│                                                                                │
│ Best For: Learning, testing, development                                     │
│ Cost: FREE                                                                    │
│ Time to Setup: 15 minutes                                                    │
│ Difficulty: ⭐ Easy                                                           │
│                                                                               │
│ 5 QUICK STEPS:                                                              │
│ ───────────────                                                             │
│ 1. Install XAMPP (https://www.apachefriends.org)                           │
│ 2. Extract project files to: C:\xampp\htdocs\expense-tracker (Windows)      │
│    Or: /Applications/XAMPP/htdocs/expense-tracker (Mac)                     │
│    Or: /opt/lampp/htdocs/expense-tracker (Linux)                           │
│ 3. Start Apache & MySQL from XAMPP Control Panel                            │
│ 4. Open: http://localhost/phpmyadmin                                       │
│    - Create database "expense_tracker"                                      │
│    - Go to SQL tab → paste database.sql → Execute                          │
│ 5. Update credentials in config/db.php                                     │
│ 6. Open: http://localhost/expense-tracker/index.html ✅                    │
│                                                                              │
│ OR USE PHP BUILT-IN SERVER (Even Easier!):                                 │
│ ─────────────────────────────────────────                                  │
│ $ cd /path/to/expense-tracker                                              │
│ $ php -S localhost:8000                                                    │
│ Open: http://localhost:8000/index.html ✅                                  │
│                                                                              │
