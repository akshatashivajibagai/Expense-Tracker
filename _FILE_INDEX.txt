LOCAL DEVELOPMENT (Recommended - 15 minutes):

□ 1. Download XAMPP (https://www.apachefriends.org)
     └─ Choose for your OS (Windows/Mac/Linux)

□ 2. Extract all project files to htdocs:
     Windows: C:\xampp\htdocs\expense-tracker\
     Mac:     /Applications/XAMPP/htdocs/expense-tracker/
     Linux:   /opt/lampp/htdocs/expense-tracker/

□ 3. Start XAMPP Control Panel:
     Click "Start" for Apache
     Click "Start" for MySQL
     Wait until both show "Running"

□ 4. Create database:
     Open http://localhost/phpmyadmin
     Create database named "expense_tracker"
     Go to SQL tab
     Paste entire contents of database.sql
     Click Execute

□ 5. Update config:
     Edit: config/db.php
     Update username/password if needed

□ 6. Open application:
     http://localhost/expense-tracker/index.html

□ 7. Add your first expense!
     Click "➕ Add Expense" button
     Fill in form
     See it appear in table!

✅ You're done!
